01 / The problem

The problem

A job search creates many small things to remember.

Company, role, date, notes, links, and follow-up status can end up scattered across browser tabs and documents.

What the app helps with

  • Keep each application’s details together.
  • See progress across four clear statuses.
  • Find and update an application quickly.

Designed for a focused MVP

Sign in, manage applications, move cards, and review a simple dashboard. The goal is a useful personal workflow—not a recruitment platform.

05 / How it works

A request, end to end

The browser handles the interaction. Django handles the rules.

For example, when a card moves, the browser asks Django to change its status. Django checks the signed-in user, updates MongoDB, and returns the result.

01 · PRESENTATIONBrowserHTML, CSS, Bootstrap, and JavaScript show the board.
02 · REQUESTFetch + APIJavaScript sends a small authenticated status update.
03 · BACKENDDjango + DRFPython validates input and applies user-ownership checks.
04 · STORAGEMongoDB AtlasPyMongo updates the application document for that user.

06 / Technology choices

Technology stack

Each tool has a specific job.

BackendPython · Django
REST APIDjango REST Framework
Application dataMongoDB Atlas · PyMongo
AuthenticationDjango auth · SQLite
FrontendTemplates · HTML · CSS · Bootstrap
InteractionVanilla JavaScript · Fetch

Why MongoDB for applications?

Application records are stored as documents, and PyMongo makes the database operations explicit in the code.

Optional AI feature

The server can send a job description to OpenAI and save a structured summary and skill lists. The secret key stays server-side.

08 / Reflection

What I learned

From UI interactions to data ownership.

Building this project helped me understand how frontend actions travel through a backend and become persistent, user-specific data.

Backend flow: route → view → validation → database → response.
Security: validate on the server and scope records to the signed-in user.
Next improvement: use persistent hosted storage for Django accounts before relying on public deployment.
